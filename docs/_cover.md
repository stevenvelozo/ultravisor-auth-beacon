# Ultravisor Auth Beacon

> Optional Ultravisor beacon advertising the Authentication capability

- Login, session validation, and beacon-join admission for an Ultravisor mesh
- Pluggable `AuthProvider` for LDAP, OAuth/OIDC, or a custom user database
- Scrubbed-token audit trail and constant-time secret checks
- Built on `ultravisor-beacon`; no HTTP server of its own
